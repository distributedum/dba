Scenario

Each scenario loads a schedule that shows one anomaly (or a deadlock) under the weaker levels. Switch the level to see which ones prevent it. Undo (Ctrl+Z) takes back the last change of any kind, including a level switch or an opened file.

Add an operation

Each button appends one operation of the selected transaction to the schedule and re-runs it. An empty write value adds 10 for T1, 20 for T2, 30 for T3, so you can tell whose update survived. A relative write (+10, −5) uses the value the transaction last read: a read-modify-write done by the application.

Schedule

r1(x) read · w1(x+10) add 10 to the value T1 read · w1(x=5) write 5 · i1(z=50) insert · d1(z) delete · s1 read the whole table · c1 commit · a1 abort. Ctrl+Enter runs. Click an operation in the timeline to remove it.
